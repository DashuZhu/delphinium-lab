# Delphinium Lab

Исследовательский веб-сервис: Delphinium и печёночные метастазы. 24 публикации, 8 ссылок SpringerLink, русские названия и краткие резюме, DOI и оригиналы.

## Сайт

GitHub Pages: https://dashuzhu.github.io/delphinium-lab/

## Возможности

Библиотека по темам и издателям, навигатор чтения, карта доказательств, конструктор протокола, журнал экспериментов, заметки, экспорт RIS/Markdown и резервные копии JSON.

## Исходный код

`index.html` — полная версия сервиса: HTML, CSS, JavaScript, исходная библиотека и локальные WOFF2-шрифты встроены в один файл. Сайт обслуживается GitHub Pages и не требует Sites, серверной сборки или внешнего сервиса шрифтов.

`source-code.zip` — исходные файлы до объединения, лицензии шрифтов, описание дизайна, план коммерческой типографики и журнал проверок. Исходная исследовательская записка — `research-brief.md`.

## Данные

Записи хранятся в localStorage браузера на домене сайта. Между доменами данные автоматически не переносятся. Для переноса с прежнего адреса скачайте JSON-копию там и импортируйте в разделе «Данные и экспорт» на новом сайте. Резервные копии и личные записи не включены в репозиторий.

## Научные границы

Предварительная подборка, а не полный систематический обзор. Прямое клиническое подтверждение подавления печёночных метастазов Delphinium не установлено. Переводы являются переводами названий и краткими изложениями, а не полным переводом статей. Метаанализ прогноза не оценивает действие Delphinium. Редакционное предупреждение к Hoshino et al. 2015 отмечено в интерфейсе.

## Шрифты

IBM Plex Sans, Sans Condensed и Mono. Неизменённые официальные файлы, SIL Open Font License. Лицензии включены в архив исходников. Платные шрифты не приобретены.

## Разработка

Разверните `source-code.zip` в корне проекта. Редактируемые файлы находятся в `source/dist/`. После изменения HTML, CSS, JavaScript или библиотеки выполните `python3 build-site.py`. Скрипт стандартной библиотеки Python обновит корневой `index.html` и `source-code.zip`. Для локальной проверки: `python3 -m http.server 8767`.

Обзор проекта показывает введённые решения. Библиотека оформлена списком; у каждой статьи есть отдельный адрес `#source-ID`, русский разбор, ограничения и форма оценки. Протокол показывает незаполненные основные поля; текст можно открыть отдельно и экспортировать.
