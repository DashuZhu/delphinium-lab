# Delphinium: исследовательский кабинет

Пользователь сопоставляет публикации о соединениях Delphinium и механизмах печёночного метастазирования, выбирает источники, фиксирует их ограничения и формулирует доклинический протокол.

Рабочий путь: обзор проекта → библиотека → разбор статьи → подборка → протокол → записи экспериментов. Порядок чтения и матрица применимости помогают выбрать литературу. Экспорт RIS, Markdown и JSON позволяет продолжить работу вне кабинета.

Это предварительная библиотека из 24 источников (8 SpringerLink), а не выполненный систематический обзор или метаанализ эффективности. Библиографические данные, модели, краткие изложения и ограничения сохраняются при изменениях дизайна. Редакционное предупреждение Hoshino et al. 2015 показывается отдельно. Не подменять Delphinium дельфинидином.

Записи хранятся в localStorage на домене сайта. Сохранённый ключ `delphinium-lab-v1` и формат версии 1 должны оставаться совместимыми. Автоматической синхронизации и серверных аккаунтов нет. Личные данные, бэкапы и результаты экспериментов пользователя не публикуются в репозитории.

Платформа: статический GitHub Pages, main / root. `source/dist` содержит редактируемые файлы; `python3 build-site.py` создаёт автономный `index.html` и архив исходников. Шрифты локальные, лицензии OFL сохранены.
